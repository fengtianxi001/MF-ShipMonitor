# 船舶数字孪生大屏

## 依赖环境

> 推荐使用 node@20.19.2

## 项目启动

> npm install

## 项目功能介绍
- [x] Threejs + Vue3 + Vite 架构。
- [x] Marker点位。
- [x] 添加进场动画。
- [x] 界面响应式布局，自适应。
- [x] 代码简洁清晰，资源压缩、性能强劲。
- [x] 参数监测、历史功率、日发电量监测、运行监测、故障对比、偏航角度监测。
